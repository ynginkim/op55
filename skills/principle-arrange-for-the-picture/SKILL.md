# 영상에 맞춘 편곡

**Why:** 장르 이름만 보고 palette를 고르면 소리가 화면과 따로 논다. 영상이 재질과 장면을 바꾸는 지점에서 소리가 그대로면 음악이 장면을 돕지 못한다.

**Pattern:** 섹션은 영상의 막을 따르고 시작은 다운비트에 둔다. 계획한 시작 근처의 다운비트에 컷이 있으면 컷을 따른다. 화면이 재질을 바꾸면 소리도 재질을 바꾼다. 예를 들어 split-flap 보드에는 시계 tick과 flap 클릭, 종이 책상에는 머뭇거리는 pluck과 연필 소리, 감열 프린터에는 32분음표 stepper가 맞는다. palette는 영상의 성격으로 고른다(기술·설명은 synth, 감정·실제 악기는 sampled, 대부분은 둘 다). 큰 hit는 화면의 hit 지점에서 다운비트마다 한 가지씩 쌓아 화성 해결로 도착시킨다. 기계적인 장면은 격자에 정확히 두고, 화면이 머뭇거리는 곳에서만 swing과 humanize를 쓴다.

**Stop:** 영상 없이 분위기만 받은 독립 BGM에는 적용하지 않는다. 그때는 사용자가 준 mood와 참고 곡을 따른다.
