# Support

Read the README and any linked guides first. For a reproducible defect, open a bug issue in [this repository](https://github.com/ynginkim/op55/issues) with the exact commit, runtime, expected result, and redacted reproduction. Use a feature request for a proposed change. Private repositories require existing access; a link does not grant access.

There is no guaranteed support schedule. Never post API keys, private prompts, personal data, or vulnerability details. Security reports follow [SECURITY.md](SECURITY.md).
